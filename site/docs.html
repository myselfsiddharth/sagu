Install

You need a Mac signed in to Messages with your Apple ID, and Python 3.9 or newer (python3 --version). Sagu uses only the standard library, so there is nothing to pip install.

git clone https://github.com/myselfsiddharth/sagu.git
cd sagu
python3 -m sagu doctor

doctor checks two permissions and tells you how to fix each:

  • Full Disk Access for your terminal app (System Settings > Privacy & Security), so Sagu can read the Messages database.
  • Automation: allow your terminal to control Messages, so Sagu can send.

Try it without sending anything:

python3 -m sagu run --dry-run

Replies are printed as DRY RUN -> .... When you are happy, drop --dry-run. Leave it running in a terminal; the Mac must stay awake.

Start with a test group. Sagu sends real messages once it is live. Make a group with one or two friends first.

Start in a chat

Sagu does nothing in a chat until you, the person whose Mac it runs on, text sagu on there. Texting from your phone works, as long as the message reaches your Mac. To switch it off: sagu off. To also delete everything it knows about the chat: sagu forget this chat.

Commands

Everything starts with "sagu".

sagu i'm AlexanyoneTell Sagu your name. It never quotes someone it has no name for.

sagu spare meanyoneOpt out and delete your saved quotes.

Games

One game runs per chat at a time; starting a new one replaces it. Games live in memory, so a restart clears them and the scoreboard.

GameHow
Triviasagu trivia, then sagu 1, sagu 2 or sagu 3. One try each. Winner gets 1 point.
Guess the numbersagu guess, then sagu 25. 12 tries. Winner gets 1 point.
Hangmansagu hangman, then sagu letter e. 6 misses. Whoever finishes the word gets 2 points.
Would you rathersagu wyr, then sagu a or sagu b. Sagu keeps a running tally.
8-ballsagu 8ball will it rain?
Pickersagu pick pizza, tacos or sushi
Coin and dicesagu flip, sagu dice, sagu dice 2d20
Scores and stopsagu scores, sagu stop

Set your name with sagu i'm Alex so scores show a real name.

Deals and rallying

Someone texts sagu deal: 2-for-1 tacos at Taco Loco till Friday. Sagu announces it and asks who is in. Replies of in, i'm in or down count; out removes you. When enough people are in, Sagu proposes a time and sends a reminder an hour before. It does not book anything anywhere; it just nudges people. You can also add RSS or Atom feeds of local deals with feeds in the config.

Config

Optional file ~/.config/sagu/config.json (override the folder with SAGU_HOME):

{
  "owner_name": "Sid",
  "prob": 0.25,
  "quiet_start": 23,
  "quiet_end": 9,
  "min_gap": 5400,
  "max_per_day": 4,
  "chatty": true,
  "spont_every": 10800,
  "feeds": [],
  "llm": false
}

chatty lets Sagu speak up on its own: a greeting about once a day and a friendly comment roughly every spont_every seconds per chat (on average), only outside quiet hours, within the daily cap, and never twice in a row into a silent chat. Set it to false for a Sagu that only answers. prob is the chance a live message triggers a jump-in. Quiet hours are local time. Other commands: python3 -m sagu groups lists your group chats, python3 -m sagu demo plays a labeled simulation, python3 -m sagu reset deletes everything Sagu remembers.

Privacy and hard lines

  • The Messages database is opened read-only. Sagu stores nothing in a chat until you say sagu on.
  • Only people who said sagu roast me are quoted.
  • Everything stays in ~/.config/sagu. Nothing leaves your Mac unless you set "llm": true and export ANTHROPIC_API_KEY. Then the quote and the person's first name are sent to write the line. Model text is validated, retried once, then replaced by the curated lines.
  • A filter on everything stored and sent blocks jokes about bodies, weight, looks, eating, race, religion, gender, sexuality, disability, mental health, family or money, plus slurs, threats and sexual content.

Troubleshooting

ProblemTry
Nothing happens after sagu onCheck the message appears in Messages on the Mac (same Apple ID on phone and Mac; for green-bubble groups enable Text Message Forwarding). Make sure it is a group chat, not one person. Restart Sagu, wait for the "listening" line, and send again.
doctor cannot read the databaseAdd your terminal app under Full Disk Access, then fully quit and reopen it.
doctor cannot control MessagesAllow your terminal under Privacy & Security > Automation.
Sagu is silent in a chatOnly the host can turn it on. Quiet hours also hold back unprompted jump-ins (not replies to commands).
Lines stop after a restartChats stay on, but games and scores reset.

Known limits: macOS only, the Mac must be awake, replies can lag a few seconds, and it works by polling.
